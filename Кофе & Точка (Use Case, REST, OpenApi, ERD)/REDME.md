## Системный аналитик | Управление лояльностью кофейни ("Кофе & Точка")

Технологии: BPMN, Use Case диаграмма, Use Case, ERD, REST, OpenAPI 

Разработала ТЗ с вариантами использования для 3 модулей: клиентское приложение, приложение бариста, админ-панель. Описала бизнес-правила начисления. Построила ERD, спроектировала REST API, описала спецификацию в OpenAPI.
