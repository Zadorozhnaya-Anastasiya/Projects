## Системный Аналитик | Система Управление Закупками "Славный пекарь"

Технологии: Use Case Диаграмма, Use Case, State Machine Diagram, ERD, ФТ, НФТ, Прототипы

Разработала ТЗ на 200+ функциональных требований. Описала 12 вариантов использования, диаграммы статусов для 4 сущностей, ролевую модель для 6 ролей. Проработала сквозной процесс: от загрузки расходов до закрытия заказов в 1С. Учла подсказки по остаткам и ценам, автоматизацию согласования, интеграцию с поставщиками через ссылки без авторизации.

Полный комплект документации для разработки. Единое понимание бизнес-логики командой. Готовая ролевая модель и статусная модель заказа.
