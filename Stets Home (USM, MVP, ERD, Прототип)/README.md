## Системный аналитик | Управление умным домом (MVP)
Технологии: USM, DFR, ERD, ISD, Прототипы

На основе расшифровок интервью составила User Story Map, выделила MVP: дом, комнаты, лампочки, управление (вкл/выкл/эко-режим), простые сценарии. Построила DFD, ERD и словарь данных. Сделала прототипы в Figma. Подготовила видео-презентацию и ПМИ.
